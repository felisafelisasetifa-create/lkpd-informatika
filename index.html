Pertanyaan Pemantik: "Jika ada dua cara menyelesaikan masalah yang sama, bagaimana kita menentukan cara yang lebih baik?"

1. Pengertian & Alasan Membandingkan Algoritma

Algoritma adalah urutan langkah-langkah yang logis, terstruktur, dan sistematis untuk menyelesaikan masalah. Suatu masalah sering kali memiliki lebih dari satu algoritma untuk menyelesaikannya.

Kita perlu membandingkan algoritma untuk memastikan solusi yang dipilih tidak hanya **benar**, tetapi juga **efisien**, **mudah dipahami**, serta **hemat langkah dan memori**.

3 Kriteria Utama Perbandingan

  • a. Kesederhanaan Seberapa mudah algoritma dipahami, ditulis, dan dibaca.
  • b. Jumlah Langkah Banyaknya operasi/perbandingan yang dilakukan untuk hasil akhir.
  • c. Efisiensi Penghematan waktu proses dan memori komputasi saat data membesar.

2. Studi Kasus: Mencari Nilai Terbesar dari [5, 8, 3, 12, 7]

Cara A: Pencarian Langsung

4 Perbandingan

Memeriksa angka satu per satu dari kiri ke kanan dan memperbarui nilai terbesar sementara.

// Pseudocode Pencarian Langsung

terbesar = angka[0]

UNTUK setiap nilai dalam angka:

JIKA nilai > terbesar:

terbesar = nilai

TAMPILKAN terbesar

Cara B: Pengurutan (Bubble Sort)

10 Perbandingan

Mengurutkan seluruh angka dari terkecil ke terbesar lebih dulu, lalu mengambil angka paling akhir.

// Pseudocode Bubble Sort

UNTUK i dari 0 sampai n-2:

UNTUK j dari 0 sampai n-i-2:

JIKA angka[j] > angka[j+1]:

TUKAR angka[j] dengan angka[j+1]

TAMPILKAN angka[n-1]

📖 Panduan 1 Menit Menyiapkan Google Sheet Otomatis untuk Guru
  1. Buat file baru di Google Sheets.
  2. Buka menu Extensions (Ekstensi) > Apps Script.
  3. Hapus semua kode di sana, lalu salin dan tempel kode otomatis di bawah ini:
function doPost(e) { try { var data = JSON.parse(e.postData.contents); var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); if (sheet.getLastRow() === 0) { sheet.appendRow(["Waktu", "Nama Siswa", "Kelas", "Kelompok", "Anggota", "Jawaban Q1", "Langkah A", "Langkah B", "Analisis Q3", "Analisis Q4", "Refleksi", "Skor Kuis"]); } sheet.appendRow([data.timestamp, data.nama, data.kelas, data.kelompok, data.anggota, data.lkpdQ1, data.lkpdQ2a, data.lkpdQ2b, data.lkpdQ3, data.lkpdQ4, data.lkpdQ5, data.quizScore]); return ContentService.createTextOutput(JSON.stringify({"result":"success"})).setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({"result":"error", "message": err.toString()})).setMimeType(ContentService.MimeType.JSON); } }

4. Klik tombol Deploy (Terapkan) > New deployment (Deployment baru) > Pilih tipe Web app.

5. Atur Execute as: Me dan Who has access: Anyone (Siapa saja). Klik Deploy dan berikan izin.

6. Salin URL Web App yang dihasilkan, lalu tempel di kotak di atas!
